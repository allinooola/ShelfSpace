Sobre o ShelfSpace 📚

Conheça o projeto, a autora e as tecnologias por trás desta biblioteca digital.

📚 O que é o ShelfSpace?

O ShelfSpace é uma biblioteca digital pessoal, um espaço na internet dedicado ao universo dos livros. Aqui você encontra reviews honestas, listas de leituras e um convite para compartilhar a sua própria opinião literária. O nome "ShelfSpace" (espaço na prateleira, em inglês) traduz exatamente o que o projeto propõe: um cantinho reservado para os livros que marcam a vida da gente.

✍️ Sobre a autora

Oi! Eu sou a Lara Vitória, estudante de Análise e Desenvolvimento de Sistemas e apaixonada por livros. Este projeto nasceu como parte de uma avaliação acadêmica, mas foi desenvolvido com carinho de verdade porque misturar tecnologia com leitura é uma das combinações favoritas por aqui. Sempre acreditei que todo livro bom merece um lugar especial, e foi isso que inspirou o ShelfSpace.

💡 Por que este projeto?

  • Livros sempre foram uma forma de escapar para outros mundos, e, criar um site sobre eles foi a maneira de juntar duas paixões numa só.
  • A ideia de poder registrar e compartilhar opiniões sobre leituras tornou o projeto ainda mais especial.
  • O ShelfSpace também é um espaço de aprendizado: cada linha de código aqui foi escrita com dedicação e vontade de evoluir.
  • No fim, este site é um convite: venha explorar, ler, e compartilhar o que os livros fazem por você.

🛠️ Tecnologias utilizadas

Este site foi desenvolvido utilizando apenas as tecnologias fundamentais do desenvolvimento web front-end, sem o uso de frameworks ou bibliotecas externas:

HTML5 CSS3 JavaScript

A estrutura de cada página é definida em HTML, a apresentação visual é controlada por um arquivo CSS centralizado, e a interatividade, como o carrossel de categorias, a validação do formulário e a exibição dos dados enviados é feita com JavaScript.
