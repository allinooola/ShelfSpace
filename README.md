📚 ShelfSpace

ShelfSpace é uma plataforma web desenvolvida como projeto acadêmico para a disciplina de Desenvolvimento Web.
O objetivo do projeto foi criar um ambiente onde leitores podem explorar livros, compartilhar avaliações e organizar suas leituras de forma simples e intuitiva.

FUNCIONALIDADES

Autenticação
- Cadastro de usuários
- Login de usuários
- Senhas protegidas com Hash
- Controle de acesso utilizando sessões
- Proteção de páginas privadas contra acesso sem autenticação

Gerenciamento de Livros
- Catálogo de livros
- Lista de leitura
- Lista de livros lidos
- Visualização das informações dos livros

Sistema de Reviews
- Criar avaliações
- Editar avaliações
- Excluir avaliações
- Visualizar avaliações dos usuários

Perfil
- Perfil do usuário
- Sessão personalizada após login

TECNOLOGIAS UTILIZADAS
- HTML5
- CSS3
- JavaScript
- PHP
- MySQL

SEGURANÇA

As senhas dos usuários são armazenadas utilizando criptografia por hash, garantindo maior segurança durante a autenticação.

APRENDIZADOS

Durante o desenvolvimento deste projeto foi possível praticar conceitos como:
- Desenvolvimento Full Stack
- CRUD completo (create, read, update, delete)
- Manipulação de Sessões (`$_SESSION`)
- Integração entre PHP e MySQL
- Modelagem e manipulação de banco de dados
- Validação de formulários
- Autenticação de usuários
- Estruturação de aplicações web


ALGUMAS MELHORIAS PLANEJADAS:
- Sistema de favoritos
- Pesquisa por livros
- Filtros por categoria
- Upload de foto de perfil
- API para busca automática de livros

> Curiosidade:
